# Service report — sensor recalibration

## Service report — sensor recalibration

**Site:** Glacier Bay Storage
**Visit date:** 2026-04-03
**Technician:** Zara Byrne (z.byrne)

### Scope
Routine follow-up on reported temperature discrepancy, unit TK04, room D.

### Findings
- Air sensor on TK04 was cross-checked against a calibrated reference probe and found to be reading approximately 3.1 C high.
- No mechanical faults, wiring issues, or door seal problems were observed on the unit itself.
- Site contact reported the offset had built up gradually, over roughly two weeks, before the discrepancy became noticeable enough to flag.

### Action Taken
- Sensor was recalibrated in place to bring readings back in line with the reference probe.
- Post-calibration readings verified stable and matching reference within tolerance before departure.

### Recommendation
Given the gradual drift pattern, suggest shortening the routine calibration interval for TK04 and confirming logging alerts are set to flag slow offset trends earlier, rather than relying on manual observation alone.
