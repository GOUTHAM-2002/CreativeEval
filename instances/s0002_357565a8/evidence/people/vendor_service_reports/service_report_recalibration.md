# Service report — sensor recalibration

## Site: Borealis Coldchain

**Visit date:** 2026-06-27
**Engineer:** Felix Okafor (f.okafor)

## Findings

- Attended site to investigate temperature discrepancy reported on unit VX04, room D.
- Cross-checked VX04's air sensor against a calibrated reference probe. The unit sensor was reading approximately 3.2 C high relative to the reference, indicating significant drift.
- Recalibrated the VX04 air sensor in place and re-verified against the reference probe post-adjustment; readings aligned within acceptable tolerance afterward.

## Customer Input

- Site staff advised that the drift had built up gradually over roughly two weeks prior to the visit, and had not been flagged for service until the discrepancy became noticeable during routine checks.

## Recommendation

- Suggest reviewing sensor calibration intervals for room D units and considering more frequent reference checks to catch slow drift earlier, before it affects stored product monitoring accuracy.

Report filed by f.okafor.
